# PaKaChi working agreements

- Commit ongoing development on `develop`.
- Integrate verified milestones into `main`; do not leave a completed milestone only in an open pull request.
- Before milestone integration, verify tests, production build, relevant browser behavior and available CI results. Inspect failed checks and fix their causes.
- Keep the roadmap current; document versioned changes in `docs/CHANGELOG.md` and checks in `docs/PRUEFUNG.md`.
- Prioritize image-to-3D character quality and rigging before the reversible standard transformation.
- General Studio tools must work on user models. Character-specific landmarks are reference/evaluation data, not an automatic anatomy detector.
